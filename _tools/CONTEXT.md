# _tools: the lab's scripts

This folder's job: the scripts every stage runs, from the repo root with Node 20+. `harness.mjs` runs sets against the persona; `check.mjs` (with `scan.mjs` and `leak.mjs`) is the gate; `index.mjs` builds both indexes; `talk.mjs` and `hermes-drive.mjs` carry live and outside-model sessions; `habits.js`, `repeats.js`, `stock.js` and `after440.js` count habits, reading through `transcripts.cjs`, which stops on empty or broken input instead of counting nothing. `selftest.mjs` plants one defect per guard and fails if any guard misses it; run it after changing any tool. `lib.mjs` is shared: the persona folder (`PERSONA_DIR`), the start message, and the model call.
